The Lean proof of the Riemann Hypothesis, stage by stage

Map, not proof. Several independent kernels accept the code. This page only shows its shape and labels what is checked and what is a reading.

Everything hangs on one half-plane

The five theorems in Main.lean are stated against Mathlib's own definitions. All five come from one statement, which the code calls EveryCharacter: for every modulus N and every Dirichlet character χ, L(s, χ) has no zero with Re s > ½ (the pole of ζ at s = 1 excepted).

From there to the Riemann Hypothesis is classical and uses only Mathlib. Take χ trivial to get no zeros of ζ right of the line. A zero left of the line would reflect through the functional equation to a zero on the right, unless it is a trivial zero. In the code this is rhOfAll → rh_of_every → rh_of_right.

So all 175,187 files serve one goal: proving EveryCharacter, the Generalized Riemann Hypothesis for Dirichlet L-functions.

Eight short theorems carry the whole weight

Below EveryCharacter the proof runs down a chain where each link is a few lines long and the work sits in branches hanging off it. Bars show each branch's size: the number of declarations that only it leads to, out of the 769,260 the top theorem uses. Open a theorem to see its branches.

    This may reconcile two claims on Zulip. At the file level nothing is dead code. At the declaration level about 292,000 declarations are never reached from the top theorem, and that may be the "unreachable" code Kevin Barreto saw. tamnd's resolver is approximate, so treat the exact figure with care.

    Most of what is used is theorems (597,752), then definitions (130,322). The longest chain of uses from the top is 175 declarations deep; the longest import chain is 203 modules.

    Some names from the note never appear in the code

    Alpöge's note ends with a 20-step timeline from 6 October to 16 November 2026. I searched all 175,187 files for each idea's name, matching whole words in CamelCase identifiers and paths. Theta lifts, seesaws, Bessel periods and covolumes are everywhere. Stepanov, Guinand–Weil, "relative trace formula" and Vandiver never appear, so those steps live in the code under other names, or were dropped on the way.

    Counts are files whose text contains the term as whole words. A name match is not a semantic match: "Bessel period" in a file name does not show that file proves step 12. Summaries are mine. Read the note for the author's words.

    A community reading of the core mechanism

    Unverified. This is Jonas Whidden's AI-assisted reading, posted on the Lean Zulip at 5:14 PM on 20 November, paraphrased. I checked only that each Lean name he cites exists at the file he gives. I did not check that these declarations lie on the path from riemannHypothesis, or that the reading is right.

    The note says a chain of theta lifts imitates the multiplicity in Stepanov's method over function fields, and that the right chain length for a von Mangoldt sum of length X is √X. The reading says that charging each lift's cost separately stalls at exponent 2/3. The fix is to track divisibility along the whole chain inside one integral lattice.
